# 報告スライドの骨子 — ETT 油温予測 PoC（v4）

作成 2026-09-17（v1）、2026-09-18 に v3 へ作り直し、2026-09-23 に v4（文字を減らした版）。読み手: クライアントの保全・データ担当（ML の知識あり）。
作法: タイトルは言いたいことを 1 文で書き、タイトルだけを順に読めば話が通るようにする。白背景（表紙と結論だけ紺）、Arial、色は紺・青・橙の 3 色まで、飾りは使わない。ページ番号と出典を各ページに入れる。
v4 で変えたこと: タイトルを 1 行にする。グラフのページの説明は 1〜2 項目に絞り、注目点は図に直接書く。文字だけのページ（背景・評価のやり方・設計の判断・限界・結論・付録 D）は図か表に置き換える。評価のやり方の 2 枚は 1 枚にまとめ、予測と実測を重ねた 1 週間の図を足した。要旨・問い・安定性の 3 枚は v3 の形のまま。
見せ方: 表の上端に紺の罫線、見出し行に薄い灰色の塗りと罫線。説明は項目ごとに細い線で区切り、そのページの主張を支える項目だけ紺の太字にする。比較手法の棒は、比べる相手（最良の比較手法）だけ濃い灰色にし、減少率には比較の基準（「リッジ比」「履歴だけ比」）を添える。
数値は `reports/slide_data.json`（`scripts/export_slide_data.py` が `reports/results_*` と `reports/predictions/` から作る）。
